Nox Vault Companion

Legacy Chrome · in-page sidebar

Firebase

The extension uses Firebase Authentication and Firestore REST directly. Paste the same Web API key already used by your Nox Vault website. The API key is not a Firebase Admin secret.

How the sidebar works

This build is compatible with older Chrome versions that do not have the Chrome Side Panel API. Click the Nox extension icon on any normal website to show or hide Nox directly on top of the current page. Your video still plays on the original website.

Keyboard shortcuts

Panic Hide defaults to Ctrl + Shift + Y. Toggle Nox Sidebar defaults to Ctrl + Shift + U. Chrome lets you change them under chrome://extensions/shortcuts.
